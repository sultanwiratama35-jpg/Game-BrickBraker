G. Kesimpulan
Modifikasi pada game Block Breaker berfokus pada pembaruan tampilan
visual dengan tema Soft Arcade -- Permata Pelangi. Perubahan
meliputi background, bentuk dan warna balok, paddle, bola, panel skor
dan nyawa, judul permainan, maskot robot, dekorasi, serta tampilan Game
Over.

Mekanisme dasar permainan tetap dipertahankan sehingga game masih
sederhana untuk dimainkan. Dengan pembaruan visual tersebut, tampilan
game diharapkan menjadi lebih menarik, berwarna, dan memiliki karakter
tersendiri.
